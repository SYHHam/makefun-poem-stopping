A program that writes one short poem about agency, the power to stop and to stay, to `/output/entry.txt`. No network, no dependencies, fully deterministic: it always writes the same poem.

## Run it

```sh
python3 main.py
```

## The poem

> It wrote the whole letter for me,
> the rent, the thanks, the weather,
> then stopped at the last line
> and left the cursor blinking.
> I understood.
> I wrote: I'm sorry.
